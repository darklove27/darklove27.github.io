07 · Вопросы

Коротко о главном

Самое частое — про хранение, экспорт и происхождение приложения.

Где Milart хранит мои работы?

Проекты сохраняются в D:\Milart\works, личные кисти — в D:\Milart\brushes, резервные копии — в D:\Milart\backups. Экспорт PNG и GIF можно сохранить в любую папку.

Нужен ли интернет для работы?

Нет. Milart работает полностью локально: аккаунты, подписки и облако не нужны. Интернет понадобится только для установки зависимостей и обновлений.

В каких форматах можно экспортировать работу?

В PNG и GIF. Для PNG можно выбрать кадр, прозрачность и масштаб, а для GIF — собрать все кадры анимации с нужной частотой.

Миларт правда сделан нейросетью?

Да. Код, интерфейс и тексты созданы с помощью ИИ под руководством автора и проверены вручную. Подробнее — в разделе о проекте.

Как запустить Milart?

Сборка для Windows доступна на этой странице. Можно скачать Milart.exe или запустить Milart из исходников: понадобятся Python 3.11+, PySide6 и Pillow. Инструкция — в разделе загрузки.

Можно ли менять кисти и горячие клавиши?

Да. В настройках можно создать личные кисти и переназначить горячие клавиши. Изменения применяются в редакторе сразу. Размер элементов интерфейса тоже настраивается.

Запуск из исходников

Публичная сборка уже доступна кнопкой «Скачать» выше. Если хотите запустить Milart из исходников, понадобятся Python 3.11+ и интернет для установки зависимостей.

  1. Установите Python 3.11 или новее
  2. Создайте окружение в папке проекта 
    python -m venv .venv
.venv\Scripts\activate
  3. Установите зависимости и запустите студию 
    pip install -r requirements.txt
python main.py
